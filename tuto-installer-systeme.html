🖥️ Installer un système : Windows & Linux

🎯 Avant de commencer

Ce tuto installe Windows 11 🪟Linux Mint 🐧 pas à pas. Change de système avec les boutons en haut.

Ce qu'il te faut
  • Une clé USB bootable avec l'ISO (voir le tuto « Clé USB bootable : Rufus & Ventoy »)
  • Un PC branché sur secteur, avec une connexion Internet
  • Une sauvegarde de tes fichiers
  • Environ 45 minutes
Deux façons d'installer
  • Remplacer l'ancien système : tout le disque est effacé.
  • Garder les deux (double démarrage) : Windows et Linux sur le même PC. Voir le chapitre dédié.
⚠️ Une installation qui efface le disque supprime tous tes fichiers. Sauvegarde avant.

🧰 Préparer le PC

  1. Sauvegarde tes documents, photos et favoris du navigateur sur un disque externe ou dans le cloud. Pense aussi à noter tes mots de passe et licences.
  2. Vérifie que ton PC est assez puissant :
    ÉlémentMinimum pour Windows 11
    Mémoire (RAM)4 Go
    Stockage64 Go
    Processeur64 bits, 2 cœurs, 1 GHz
    SécuritéUEFI avec Secure Boot, puce TPM 2.0
    Pour voir si ton PC a un TPM : touches Windows+R, tape tpm.msc.
    ÉlémentMinimum pour Linux Mint
    Mémoire (RAM)2 Go (4 Go conseillés)
    Stockage20 Go
    Écran1024 × 768
    Linux Mint tourne très bien sur un PC ancien.
  3. Branche le PC sur secteur (ou garde la batterie bien chargée) : il ne doit pas s'éteindre pendant l'installation.

🚀 Démarrer sur la clé USB

  1. Branche la clé et redémarre le PC.
  2. Dès le logo, appuie plusieurs fois sur la touche du menu de démarrage : F12 (Dell, Lenovo, Acer, Gigabyte), F9 (HP), F8 (Asus) ou F11 (MSI).
  3. Choisis ta clé dans la liste (souvent « UEFI : nom de la clé »).
  4. Si tu utilises Ventoy, choisis l'ISO voulue dans son menu.
💡 Si la clé n'apparaît pas, le chapitre « Dépannage » du tuto Rufus & Ventoy t'aide.

🪟 Installer Windows 11

  1. L'écran de l'installateur apparaît. Choisis la langue, le format de l'heure et le clavier (« Français (Belgique) » ou « Français », selon ton clavier), puis Suivant.
  2. Clique sur Installer maintenant.
  3. Clé de produit : saisis-la si tu en as une. Sinon clique sur « Je n'ai pas de clé de produit » : si ce PC avait déjà Windows activé, il se réactivera tout seul après l'installation.
  4. Choisis la version (Famille ou Pro, selon ta licence) et accepte les conditions.
  5. Choisis « Personnalisé : installer uniquement Windows ».
  6. Choix du disque :
    • Pour tout remplacer : sélectionne chaque partition de l'ancien système, clique sur « Supprimer », puis choisis l'« Espace non alloué ».
    • Clique sur Suivant : Windows crée ce qu'il faut tout seul.
  7. La copie des fichiers commence et le PC redémarre plusieurs fois. Quand l'écran dit « Appuyez sur une touche pour démarrer depuis le CD ou DVD… », n'appuie sur rien : l'installation continue depuis le disque.
  8. Première configuration : région, clavier, connexion au réseau, puis compte. Windows 11 demande en général un compte Microsoft. Si tu préfères un compte local, l'option « ne pas exiger de compte Microsoft » de Rufus le permet (voir le tuto Rufus).
  9. Réponds aux questions de confidentialité (tu peux tout refuser), et ton bureau apparaît 🎉
⚠️ Si aucun disque n'est proposé à l'étape 6, ton PC a besoin d'un pilote de stockage (Intel RST / VMD). Clique sur « Charger un pilote » et pointe vers le pilote téléchargé sur le site du fabricant.

🐧 Installer Linux Mint

Mint se lance d'abord en mode « live » : tu peux l'essayer sans rien modifier.

  1. Dans le menu de démarrage, choisis « Start Linux Mint ». (En cas d'écran noir, redémarre et prends le « Compatibility mode ».)
  2. Le bureau apparaît. Essaie-le librement : rien n'est installé tant que tu ne lances pas l'installation.
  3. Double-clique sur l'icône « Install Linux Mint » sur le bureau.
  4. Choisis la langue, puis le clavier. Tu peux taper dans la zone de test pour vérifier que les touches sont bonnes.
  5. Connecte-toi au Wi-Fi si besoin et coche « Installer les codecs multimédia » : tes vidéos et ta musique marcheront tout de suite.
  6. Type d'installation :
    • « Effacer le disque et installer Linux Mint » : remplace tout, c'est le plus simple.
    • « Installer Linux Mint à côté de Windows » (proposé si Windows est détecté) : double démarrage.
  7. Confirme les modifications sur le disque (Continuer), puis choisis ton fuseau horaire.
  8. Entre ton nom, le nom de l'ordinateur, un identifiant et un mot de passe que tu retiendras.
  9. L'installation dure environ 10 à 20 minutes. À la fin, clique sur Redémarrer maintenant, retire la clé quand c'est demandé et appuie sur Entrée.

🔀 Garder Windows et Linux ensemble

Le double démarrage : au démarrage du PC, un menu te laisse choisir.

  1. Installe Windows en premier, puis Linux ensuite. Dans l'autre sens, Windows peut écraser le menu de démarrage de Linux.
  2. Libère de la place depuis Windows : clic droit sur « Démarrer » → « Gestion des disques », clic droit sur le disque C: → « Réduire le volume ». Compte au moins 30 à 50 Go pour Linux.
  3. Désactive le démarrage rapide de Windows (Options d'alimentation → « Choisir l'action des boutons d'alimentation »). Si le disque est chiffré (BitLocker), suspends-le d'abord.
  4. Démarre sur la clé Linux Mint, lance l'installation et choisis « Installer Linux Mint à côté de Windows ».
💡 Au démarrage, un menu (GRUB) propose « Linux Mint » ou « Windows Boot Manager ».

✅ Après l'installation

  1. Mises à jour : Paramètres → Windows Update → « Rechercher des mises à jour ». Répète jusqu'à ce qu'il n'y ait plus rien.
  2. Pilotes : vérifie que le Wi-Fi, le son et l'écran marchent. Sinon, prends les pilotes sur le site du fabricant du PC.
  3. Sécurité : Microsoft Defender est déjà là et suffit pour la plupart des gens.
  4. Récupération : tape « Créer un point de restauration » dans la recherche pour pouvoir revenir en arrière.
  1. Mises à jour : ouvre le « Gestionnaire de mises à jour » et installe tout. Ou en terminal : 
    sudo apt update && sudo apt upgrade
  2. Pilotes : ouvre le « Gestionnaire de pilotes » : il propose les pilotes de la carte graphique ou du Wi-Fi si nécessaire.
  3. Sauvegardes : lance Timeshift (déjà installé) pour créer un premier instantané du système.
  4. Logiciels : le « Gestionnaire de logiciels » installe des applications en quelques clics (pas besoin de chercher des .exe).

🩺 Dépannage

Le PC redémarre sur l'installateur après l'installation

Retire la clé USB, ou place le disque interne en premier dans l'ordre de démarrage du BIOS.

Écran noir ou figé au démarrage de la clé

Choisis « Compatibility mode » dans le menu de Linux Mint.

Essaie un autre port USB, ou recrée la clé en changeant GPT / MBR.

Pas de Wi-Fi après l'installation

Télécharge le pilote Wi-Fi depuis un autre appareil, sur le site du fabricant du PC, puis installe-le.

Ouvre le « Gestionnaire de pilotes » : le pilote est souvent proposé là (connecte-toi en câble Ethernet pour le télécharger).

Windows a disparu du menu après l'installation de Linux

Dans un terminal Linux :

sudo update-grub

Le menu est reconstruit et Windows réapparaît.
